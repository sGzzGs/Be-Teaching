# Be Teaching (v1.0)

Escolha a versão ideal para você:

1. **Versão Portátil (`Be Teaching v1.0 - Portatil (Sem Dependencias).exe`)**: Recomendada para a maioria. Roda direto em qualquer computador sem instalar nada.
2. **Versão Leve (`Be Teaching v1.0 - Leve (Requer .NET 8).exe`)**: Arquivo super compacto, para computadores que já possuem o .NET 8 instalado.
3. **Em caso de dúvida, utilize a versão Portátil.**
